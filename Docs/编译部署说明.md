# 编译与部署说明

## 必需组件
- Windows 10/11
- Visual Studio 2019/2022：.NET 桌面开发工作负载
- .NET Framework 4.8 Developer Pack / Targeting Pack
- PowerShell（Windows 自带）

## 本地自动编译打包
双击 `Build/build_all.bat`。脚本按以下顺序定位 MSBuild：PATH -> Visual Studio Installer 的 vswhere -> VS 2022/2019 常见安装目录。找不到时会提示安装工作负载与 Targeting Pack。

成功后生成：
- `Publish/`：应用和文档
- `Release/CursorWpf_VX.x.x.zip`
- 安装 Inno Setup 6 时额外生成 `Release/CursorWpf_VX.x.x.exe`

## GitHub Actions
- main push / PR：编译并上传 ZIP artifact。
- `v1.1.0` 等 Tag：编译、ZIP、Inno Setup 安装包，并创建 GitHub Release。
- 发布前更新 `Build/version.txt`，确保 Tag 与版本一致。
