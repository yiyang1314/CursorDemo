# 系统架构说明

- **Presentation**：`MainWindow.xaml` 负责工作区布局、资源字典样式和交互入口。
- **ViewModel**：`MainViewModel` 维护聊天消息、编辑内容、项目条目和 ICommand。
- **Models**：聊天消息与编辑文档模型。
- **Services**：主题资源切换、语言切换入口、项目文件枚举、文档辅助。
- **Themes**：Dark / Light 两套颜色资源，编辑区文字色独立于普通文本色，避免低对比度。
- **Build / CI**：本地 BAT 调用 MSBuild；GitHub Actions 使用 windows-2022 + setup-msbuild，统一版本源 `Build/version.txt`。

项目目标框架为 .NET Framework 4.8，语言版本 C# 7.3，不依赖 .NET 6+ API。
