# CursorWpf 需求说明（V1.1.0）

## 1. 项目目标
基于 WPF、.NET Framework 4.8 与 MVVM 构建 Cursor / VS Code 风格桌面工作区，重点还原顶部菜单、活动栏、项目资源管理器、AI 对话区、代码编辑区和状态栏。

## 2. 功能范围
1. 自定义 Windows 标题栏、应用图标、最小化/最大化/关闭。
2. 顶部文件/编辑/查看/帮助菜单，菜单弹出位置与一级菜单对齐。
3. 左侧活动栏、资源管理器、文件夹选择和项目项展示。
4. 中间聊天消息列表、用户输入和发送交互；本版本仅本地演示。
5. 右侧代码编辑文本区、文件打开/保存、标签栏外观和图片预览。
6. Dark/Light 主题；高对比度编辑器文字和选区。
7. 中英文切换基础服务；帮助文档入口；用户资料弹窗。
8. 本地 MSBuild 自动发现、Release 编译、ZIP/EXE 安装包。
9. GitHub Actions 在 main / PR 构建，版本 Tag 自动发布。

## 3. 非目标 / 当前限制
- 当前编辑器是 WPF TextBox，不等同于 AvalonEdit；尚无语法着色、智能补全、格式化或多文档缓冲区。
- AI 对话未连接模型 API，不具备真实推理或流式输出。
- 当前图片预览支持常见位图格式；PDF/Markdown 专业预览属于后续里程碑。
- 当前中英文切换服务入口已建立，所有界面字符串尚未全部资源化。

## 4. 验收标准
- Windows + .NET Framework 4.8 Developer Pack 环境下 Release 编译通过。
- 运行后标题栏、三栏布局、主题、菜单、文件打开/保存和用户弹窗可用。
- `Build/build_all.bat` 自动定位 MSBuild；失败时给出安装指引。
- GitHub Actions 对 main/PR 生成 ZIP；推送 `vX.x.x` Tag 时发布 ZIP 与 EXE。
