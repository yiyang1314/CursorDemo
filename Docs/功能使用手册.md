# 功能使用手册

## 启动
在 Windows 上使用 Visual Studio 打开 `CursorWpf.sln`，选择 Release / Any CPU 后启动。

## 项目和文件
点击左侧“打开文件夹”选择工作目录；点击右侧“打开”载入文本或代码文件；编辑后点击“保存”。首次保存可选择目标路径。

## 主题和语言
资源管理器底部提供深色/浅色和中文/English入口。主题即时切换。语言切换基础服务已提供，未资源化的标签将在后续版本补齐。

## 图片预览
点击编辑区工具栏“图片预览”，选择 PNG/JPG/BMP/GIF 图片。预览窗口支持缩放查看（随窗口尺寸调整）。

## 用户信息
点击左下角用户卡片可查看本地账户、工作区和版本信息。

## 帮助文档
点击顶部“帮助”或侧栏“帮助文档”打开本手册。

## 注意
AI Chat 当前为离线演示，不会连接模型服务。编辑器为基础文本编辑控件，尚未包含 AvalonEdit 的语法高亮与自动补全。
